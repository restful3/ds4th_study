# 거대 언어 모델을 이용한 지식 그래프 구축: 학습 가이드

이 가이드는 비정형 데이터(특히 역사적 기록물)로부터 거대 언어 모델(LLM)을 활용하여 지식 그래프(Knowledge Graph, KG)를 구축하고 분석하는 과정을 다룹니다. 록펠러 아카이브 센터(RAC)의 사례 연구를 바탕으로 지식 그래프의 설계, 정규화, 개체명 해소 및 그래프 데이터 과학의 가치를 학습할 수 있도록 구성되었습니다.

---

## 1. 핵심 개념 요약

### 지식 그래프 구축의 주요 단계
1.  **디지털화(Digitization):** 아날로그 타자 문서를 광학 문자 인식(OCR) 시스템을 통해 디지털 텍스트로 변환합니다.
2.  **커스텀 지식 추출(Custom Knowledge Extraction):**
    *   **개체명 인식(NER):** 텍스트에서 사람, 조직, 직업, 기술 등의 개체를 식별합니다.
    *   **관계 추출(RE):** 식별된 개체 간의 의미론적 연결(예: WORKS_FOR, TALKED_WITH)을 정의합니다.
3.  **지식 그래프 생성:** 추출된 데이터를 구조화하고 정제하여 그래프 형태로 변환합니다.
4.  **그래프 데이터 과학(Graph Data Science):** 알고리즘(PageRank, 중앙성 등)을 사용하여 네트워크 내부의 패턴과 통찰을 발견합니다.

### 지식 그래프의 3단계 계층 구조
*   **문서 계층(Document-level layer):** 데이터 수집의 초기 결과물로, 각 파일과 페이지를 노드로 나타내며 원본 텍스트 속성을 포함합니다.
*   **메타그래프 계층(Metagraph layer):** 병합되지 않은 개체(Entity) 노드들과 그들 사이의 관계를 포함하며, 추출된 원본 페이지와의 연결 정보를 유지합니다.
*   **지식 그래프 계층(KG layer):** 최종적으로 정규화, 정제 및 해소가 완료된 개체(Person, Organization 등)와 그들 사이의 의미론적 관계가 포함된 계층입니다.

### LLM 시대 지식 그래프의 가치
*   **설명 가능성(Explainability):** 결과의 근거가 되는 원본 데이터와 추론 과정을 사용자가 직접 검토하고 검증할 수 있습니다.
*   **탈-블랙박스화(De-black-boxing):** LLM의 판단에만 의존하지 않고 팩트 정보를 추출하여 구조화함으로써 결과의 신뢰도를 높입니다.
*   **민주화(Democratization):** 고비용의 LLM은 KG 생성 시 한 번만 사용하고, 이후 분석은 상대적으로 저렴한 비용으로 지속할 수 있습니다.
*   **탐색 가능성 및 고급 분석:** 데이터를 다양한 각도에서 시각화하고 복잡한 그래프 알고리즘을 적용할 수 있습니다.

## 2. 단답형 연습 문제

**문 1. 아날로그 타자 문서를 디지털 텍스트 코퍼스로 변환하기 위해 사용되는 시스템의 명칭은 무엇입니까?**
> **답:** 광학 문자 인식 (Optical Character Recognition, OCR)

**문 2. 지식 그래프 계층에서 동일한 대상을 지칭하는 다양한 이름(예: "E. Smith"와 "Eleanor Smith")을 하나로 통합하는 과정을 무엇이라 합니까?**
> **답:** 개체명 해소 (Entity Resolution)

**문 3. 지식 그래프 내에서 특정 노드가 다른 노드들 사이의 경로 상에 얼마나 자주 위치하는지를 측정하여 '다리(Bridge)' 역할을 하는 인물을 찾는 데 유용한 알고리즘은?**
> **답:** 매개 중앙성 (Betweenness centrality)

**문 4. 메타그래프 계층에서 개체 노드들을 병합하지 않고 유지함으로써 얻을 수 있는 주요 장점은 무엇입니까?**
> **답:** 데이터의 원본 출처(텍스트 스니펫)를 추적할 수 있어 설명 가능성을 높이고, 필요시 지식 그래프를 언제든 재구성할 수 있습니다.

**문 5. 직업(Occupation) 개체명을 정규화할 때, 대소문자 구분이 무의미하다고 판단될 경우 적용하는 구체적인 정제 방법은?**
> **답:** 모든 직업 개체명을 소문자(Lowercasing)로 변환합니다.

## 3. 심층 탐구를 위한 서술형 문제

**질문 1. 역사적 문서를 지식 그래프로 변환할 때 마주하게 되는 주요 도전 과제들과 이를 해결하기 위한 LLM의 역할에 대해 서술하시오.**
*   **가이드:** 역사적 문서는 현대에 더 이상 사용되지 않는 학문 분야나 용어를 포함할 수 있어 표준 NER 사전 구축이 어렵습니다. 또한 작성자마다 고유한 약어(예: "U.Cal." 등)를 사용하는 등 언어적 관습이 다릅니다. LLM은 이러한 도메인 특화된 개체를 명시적인 사전 없이도 맥락에 따라 암묵적으로 인식(NER), 해소 및 관계 추출(RE)을 수행할 수 있는 능력을 갖추고 있어 기존의 전통적인 ML 모델보다 유연하게 대응할 수 있습니다.

**질문 2. '그래프 기반 개체명 해소' 시스템이 문자열 유사도 외에 활용하는 신호들은 무엇이며, 이것이 왜 효과적인지 설명하시오.**
*   **가이드:** 그래프 구조 내에서의 관계성(RE 결과)을 활용합니다. 예를 들어 "Eleanor Smith"와 "E. Smith"가 동일한 대학(WORKS_FOR)에서 근무하거나 동일한 연구 주제(WORKS_ON)를 공유한다면 동일인일 확률이 높습니다. 또한 커뮤니티 탐지(Louvain 알고리즘 등)를 통해 특정 인물이 속한 지적 네트워크를 파악하여, 유사한 이름을 가진 서로 다른 분야의 인물을 구분하는 데 도움을 줍니다.

**질문 3. 지적 네트워크 분석(Intellectual Network Analysis)에서 중앙성 알고리즘들을 통해 발견할 수 있는 세 가지 유형의 인물과 그 의미를 설명하시오.**
*   **가이드:** 
    1.  **영향력 있는 인물(Influencers):** 타인의 작업을 추천하거나 언급하는 데 두드러진 인물.
    2.  **영향을 받는 인물(Influencees):** 타인의 추천이나 언급의 대상이 되는 인기 있는 인물.
    3.  **다리(Bridges):** 매개 중앙성이 높은 인물로, 서로 다른 연구 커뮤니티나 조직 사이를 연결하는 핵심적인 연결 고리 역할을 합니다.

## 4. 주요 용어 사전

| 용어 | 정의 및 설명 |
| :--- | :--- |
| **OCR (광학 문자 인식)** | 이미지 형태의 텍스트를 기계가 읽을 수 있는 텍스트 데이터로 변환하는 기술. |
| **NER (개체명 인식)** | 텍스트에서 인물, 조직, 장소, 기술 등 정의된 범주의 개체를 식별하는 과정. |
| **RE (관계 추출)** | 식별된 개체들 사이의 의미론적 연결(예: 'A는 B의 학생이다')을 추출하는 작업. |
| **메타그래프 (Metagraph)** | 원본 데이터와 최종 지식 그래프 사이의 중간 계층. 정제되지 않은 개체 멘션과 출처 정보를 유지. |
| **개체명 해소 (Entity Resolution)** | 서로 다른 문서나 문장에서 언급된 다양한 명칭들이 동일한 실제 개체를 가리키는지 판단하고 통합하는 작업. |
| **PageRank** | 그래프 내에서 노드의 상대적 중요도를 측정하는 알고리즘. 지적 네트워크에서 인기도를 나타내는 데 활용됨. |
| **WCC (약연결 성분)** | 그래프에서 모든 노드가 서로 연결되어 있는 부분 집합을 찾는 알고리즘. 개체명 해소 시 동일 그룹 식별에 사용됨. |
| **Cypher** | 그래프 데이터베이스에서 데이터를 쿼리하고 조작하기 위해 사용되는 선언형 질의 언어. |
| **사이클로트론 (Cyclotron)** | 입자 가속기의 일종. 본문에서는 어니스트 로런스 등 주요 과학자들의 관계망을 분석하는 핵심 주제로 등장. |
