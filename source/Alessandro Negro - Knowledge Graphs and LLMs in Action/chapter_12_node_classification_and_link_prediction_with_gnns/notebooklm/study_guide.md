# GNN을 활용한 노드 분류 및 링크 예측 학습 가이드

이 학습 가이드는 그래프 신경망(GNN)을 사용하여 노드 분류(Node Classification) 및 링크 예측(Link Prediction)을 수행하는 방법과 실제 응용 사례를 심층적으로 다룹니다. 자금 세탁 방지(AML)와 영화 추천 시스템이라는 두 가지 핵심 시나리오를 통해 GNN 모델의 구축, 훈련 및 평가 과정을 안내합니다.

---

## 1. 핵심 개념 정리

### GNN 시스템의 엔드 투 엔드(End-to-End) 프레임워크
GNN 기반 시스템은 데이터의 형태나 구체적인 작업에 관계없이 공통적인 구조를 따릅니다.

1.  **입력 데이터(Input Data):** 여러 객체와 그들 간의 상호작용을 설명하는 반정형 소스(CSV 파일 등).
2.  **그래프 프로세서(Graph Processor):** 소스 데이터를 GNN 모델의 입력으로 사용할 수 있는 그래프 형식(PyTorch Geometric 데이터 구조)으로 변환하고 전처리합니다.
3.  **인코더(Encoder):** 메시지 패싱(Message Passing)을 통해 노드의 특징을 학습 가능한 임베딩으로 변환합니다. (예: GCN, GAT, SAGE)
4.  **디코더(Decoder):** 특정 하위 작업(노드 분류 또는 링크 예측)을 최적화하기 위한 함수를 적용합니다.
5.  **훈련된 모델(Trained Model):** 추론 단계에서 사용 가능한 최종 모델을 산출합니다.

### 주요 GNN 아키텍처 모델 비교
| 모델 | 주요 특징 | 복잡도 및 효율성 |
| :--- | :--- | :--- |
| **GCN (Graph Convolutional Networks)** | 가장 효율적이며 훈련 시간이 빠름. | 파라미터 수가 적고 연산이 단순함. |
| **GAT (Graph Attention Networks)** | 이웃 노드 간의 엣지에 학습 가능한 계수를 도입하는 어텐션 메커니즘 사용. | 파라미터가 가장 많고 훈련 시간이 가장 김. |
| **GraphSAGE (SAGE)** | 이웃의 정보를 샘플링하고 집계하는 방식. | GCN과 GAT 사이의 효율성과 성능 균형을 유지. |

## 2. 노드 분류: 자금 세탁 방지(AML) 애플리케이션

노드 분류는 각 노드를 특정 범주로 분류하는 작업입니다. 금융 거래망에서는 각 계정(노드)을 '합법(Licit)' 또는 '불법(Illicit)'으로 분류하는 데 사용됩니다.

### 데이터 준비 및 전처리 (Elliptic 데이터셋)
-   **구성:** 20만 개 이상의 비트코인 트랜잭션(노드), 23만 개 이상의 결제 흐름(엣지), 166개의 익명화된 노드 특징.
-   **클래스 분포:**
    -   미분류(Unknown): 77.15%
    -   합법(Licit): 20.62%
    -   불법(Illicit): 2.23%
-   **노드 마스킹(Node Masking):** 모델이 레이블이 있는 노드에 대해서만 학습하고 평가하도록 훈련(80%), 검증(10%), 테스트(10%) 세트로 분할하여 마스크를 적용합니다.

### 분류 시스템의 디코더 및 손실 함수
-   **디코더:** `log_softmax` 함수를 사용하여 노드 임베딩을 확률 값으로 변환합니다.
-   **손실 함수:** `Negative Log-Likelihood(NLL)` 손실과 결합된 크로스 엔트로피 손실을 사용하여 모델의 예측과 실제 레이블 간의 오차를 최적화합니다.

### 성능 분석 결과 (AML 시나리오)
-   **Precision(정밀도):** SAGE 모델이 가장 높으며, 불법 노드를 오분류(False Positive)하는 경우를 최소화합니다.
-   **Recall(재현율):** 세 모델 모두 실제 합법/불법 노드를 찾아내는 능력은 비슷하게 높습니다.
-   **F1-Score:** 정밀도와 재현율의 균형을 가장 잘 맞춘 SAGE 모델이 가장 우수한 성능을 보입니다.
-   **혼동 행렬(Confusion Matrix):** GCN은 불법 노드의 약 1/3을 합법으로 오분류하는 한계를 보인 반면, SAGE는 불법 노드 분류에서 가장 낮은 오분류율을 기록했습니다.

## 3. 링크 예측: 영화 추천 시스템

링크 예측은 그래프 내의 두 노드 사이에 새로운 연결(엣지)이 형성될 가능성을 예측하는 작업입니다.

### 데이터 준비 (MovieLens 데이터셋)
-   **특징:** 사용자(User)와 영화(Movie)라는 두 가지 유형의 노드가 존재하는 이종 그래프(Heterogeneous Graph) 구조입니다.
-   **데이터 소스:** `movies.csv` (영화 ID, 제목, 장르), `ratings.csv` (사용자 ID, 영화 ID, 평점).
-   **장르 특징 벡터화:** 각 영화의 장르 정보를 원-핫 인코딩(One-hot encoding) 형태의 이진 벡터로 변환하여 20차원의 특징 벡터를 생성합니다.

### 링크 예측의 메커니즘
-   **인코더:** 이종 GNN 모델을 사용하여 사용자와 영화 노드의 임베딩을 학습합니다.
-   **디코더:** 두 노드 임베딩 간의 **내적(Dot-product)** 연산을 수행하고, 이진 크로스 엔트로피 손실(Binary Cross-Entropy Loss)을 사용하여 링크의 존재 여부를 예측합니다.

(정답: GAT - Graph Attention Networks)

**Q2. Elliptic 데이터셋에서 노드를 분류할 때, 모델 학습 시 알려진 레이블만 보이게 하기 위해 사용하는 기술은?**
(정답: 노드 마스킹 - Node Masking)

(정답: F1-Score)

**Q4. 추천 시스템에서 영화 장르와 같은 범주형 데이터를 수치적 벡터로 변환하는 과정을 무엇이라 하는가?**
(정답: 데이터 전처리 또는 장르 특징 벡터화)

(정답: 내적 - Dot-product)

## 5. 심화 학습 에세이 문제

**문제 1: GCN, GAT, SAGE 모델의 아키텍처 특성과 AML 노드 분류 작업에서의 성능 차이를 연관 지어 논하시오.**
-   *가이드:* GCN의 단순성과 효율성, GAT의 어텐션 계수 활용, SAGE의 이웃 샘플링 및 집계 방식을 비교합니다. 특히 불법 노드 감지에서 SAGE가 왜 더 우수한 균형(F1-score)을 제공하는지 데이터셋의 불균형성과 관련하여 설명해야 합니다.

**문제 2: 노드 분류와 링크 예측 작업에서 디코더(Decoder)의 역할과 차이점을 설명하시오.**
-   *가이드:* 노드 분류에서의 디코더는 단일 노드의 임베딩을 클래스 확률로 변환(log_softmax)하는 역할을 하며, 링크 예측에서의 디코더는 두 노드 임베딩 간의 관계(내적)를 통해 연결 가능성을 산출한다는 점을 명시해야 합니다.

**문제 3: Elliptic 데이터셋과 같이 클래스 불균형이 심한 데이터(Unknown 77%, Licit 20%, Illicit 2%)를 다룰 때 가중 평균(Weighted Average) 지표를 사용하는 이유를 논하시오.**
-   *가이드:* 단순 정확도(Accuracy)의 함정을 피하고, 각 클래스의 데이터 분포를 반영하여 모델의 전반적인 성능을 보다 객관적으로 평가하기 위함임을 설명합니다.

## 6. 주요 용어 사전 (Glossary)

| 용어 | 정의 |
| :--- | :--- |
| **AML (Anti-Money Laundering)** | 금융 시스템을 통한 불법 자금 세탁을 방지하고 탐지하기 위한 일련의 법률 및 기술적 절차. |
| **메시지 패싱 (Message Passing)** | 이웃 노드들로부터 정보를 수집하고 업데이트하여 각 노드의 특징을 학습하는 GNN의 핵심 과정. |
| **동종 그래프 (Homogeneous Graph)** | 단일 유형의 노드와 단일 유형의 엣지로 구성된 그래프. |
| **이종 그래프 (Heterogeneous Graph)** | 사용자-영화 관계와 같이 서로 다른 유형의 노드나 엣지를 포함하는 그래프. |
| **Precision (정밀도)** | 모델이 특정 클래스라고 예측한 것 중 실제 해당 클래스인 비율. |
| **Recall (재현율)** | 실제 해당 클래스인 전체 데이터 중 모델이 올바르게 찾아낸 비율. |
| **Log Softmax** | 수치적 안정성을 위해 소프트맥스 함수에 로그를 취한 것으로, 분류 작업의 확률 계산에 사용됨. |
| **Edge Index Tensor** | 그래프 내의 연결 정보를 노드 ID 쌍의 형태로 저장한 텐서 구조. |
