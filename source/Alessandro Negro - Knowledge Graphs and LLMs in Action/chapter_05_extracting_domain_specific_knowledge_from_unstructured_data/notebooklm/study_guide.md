# 비정형 데이터로부터 도메인 특화 지식 추출하기: 학습 가이드

이 학습 가이드는 비정형 텍스트 데이터를 구조화된 지식 그래프(Knowledge Graph, KG)로 변환하는 과정과 그 과정에서 대규모 언어 모델(LLM)이 수행하는 역할에 대해 다룹니다. 제공된 자료를 바탕으로 핵심 개념을 정리하고, 학습 내용을 확인할 수 있는 연습 문제와 심층 탐구를 위한 에세이 주제, 그리고 주요 용어 사전을 포함하고 있습니다.

---

## 1. 핵심 개념 정리

### 지식 추출의 필요성
오늘날 기업 데이터의 80%~90%는 이메일, 채팅, 연구 논문, 뉴스 기사 등 비정형 텍스트 형태로 존재합니다. 이러한 데이터에서 가치를 창출하기 위해서는 이를 구조화되고 검증 가능한 지식 표현인 '지식 그래프'로 변환하는 과정이 필요합니다.

### 지식 추출의 두 가지 핵심 프로세스
1.  **개체명 인식 (Named Entity Recognition, NER):** 텍스트 내에서 언급된 개체(사람, 조직, 장소, 연구 주제 등)를 식별하고 미리 정의된 카테고리에 할당하는 작업입니다.
2.  **관계 추출 (Relation Extraction, RE):** 텍스트 문서 내의 개체 쌍 사이의 의미론적 관계(예: "누구는 어디에서 일한다", "어떤 이론은 무엇을 연구한다")를 식별하는 작업입니다.

### 대규모 언어 모델(LLM)의 역할
전통적인 자연어 처리(NLP) 방식은 복잡한 파이프라인 구축과 방대한 양의 수동 레이블링 데이터가 필요했습니다. 반면, LLM은 **전이 학습(Transfer Learning)**을 통해 적은 양의 데이터로도 높은 정확도를 달성하며, 다음과 같은 혁신을 가져왔습니다.
*   **지능적 문맥 이해:** 약어(예: 'R.'이 'Rossby'를 지칭함)나 대명사를 문맥에 맞게 해석하는 상호 참조 해결(Coreference Resolution)을 암시적으로 수행합니다.
*   **데이터 정규화:** "Prof. Chem."을 "Professor of Chemistry"로 변환하는 등 비정형 데이터를 깔끔하고 일관된 형태로 정제합니다.
*   **유연성:** 프롬프트 엔지니어링을 통해 모델의 아키텍처 변경 없이도 다양한 도메인에 적용할 수 있습니다.

## 2. 단답형 연습 문제

**질문 1:** 기업 데이터 중 비정형 데이터가 차지하는 일반적인 비율은 어느 정도입니까?
> **정답:** 80%에서 90% 사이입니다.

**질문 2:** LLM 기반 지식 추출 시스템에서 모델이 학습 데이터에 근거하지 않은 가짜 사실이나 논리를 만들어내는 현상을 무엇이라고 합니까?
> **정답:** 환각(Hallucinations)입니다.

**질문 3:** 지식 그래프 구축 과정에서 텍스트를 디지털화하기 위해 사용하는 광학 문자 인식 기술의 약자는 무엇입니까?
> **정답:** OCR (Optical Character Recognition)입니다.

**질문 4:** LLM 설정 매개변수 중, 값이 높을수록 창의적이고 다양한 출력을 생성하고 낮을수록 결정론적인 출력을 생성하게 만드는 것은 무엇입니까?
> **정답:** 온도(Temperature)입니다. (사실 중심의 지식 추출 작업에는 0에 가까운 낮은 값을 권장합니다.)

**질문 5:** 예시 하나 없이 작업 설명만 제공하여 모델을 수행시키는 방식을 ( 1 )-shot 학습, 하나 또는 두 개의 예시를 제공하는 방식을 ( 2 )-shot 학습이라고 합니다. 빈칸에 들어갈 말은?
> **정답:** (1) Zero-shot, (2) One-shot

**질문 6:** 록펠러 아카이브 센터(RAC) 사례 연구에서 지식 추출의 주요 대상이 된 문서는 무엇입니까?
> **정답:** 프로그램 책임자들의 일기(Diaries)입니다.

## 3. 심화 학습을 위한 에세이 질문

### 주제 1: 전통적 NLP와 LLM 기반 지식 추출의 전략적 비교
전통적인 NLP 파이프라인과 LLM을 이용한 지식 추출 방식의 장단점을 비교 분석하십시오. 특히 보안, 인프라 비용, 전문 지식의 필요성, 예측 속도의 측면에서 어떤 비즈니스 환경에 어떤 방식이 더 적합한지 논하십시오.

### 주제 2: 효과적인 프롬프트 엔지니어링을 위한 주요 원칙
지식 그래프 구축을 위해 LLM을 활용할 때, 출력의 안정성과 품질을 높이기 위한 프롬프트 엔지니어링의 주요 전략들을 설명하십시오. (예: 작업 설명의 구체성, 엔터티 및 관계 클래스 명시, 대표 예시 제공 등)

### 주제 3: 생성형 AI의 '환각' 현상과 지식 그래프의 상호 보완성
LLM의 한계점인 '환각' 현상이 신뢰할 수 있는 지식 시스템 구축에 어떤 위협이 되는지 설명하고, 지식 그래프(KG)가 이러한 한계를 어떻게 보완하여 "구조화되고 검증 가능한 지식 표현"을 제공할 수 있는지 서술하십시오.

## 4. 주요 용어 사전

| 용어 | 정의 |
| :--- | :--- |
| **지식 그래프 (Knowledge Graph)** | 고립되고 분산된 정보를 정렬되고 연결된 버전으로 모델링하여 컴퓨터와 인간이 자율적으로 접근할 수 있게 만든 지식 표현 형태. |
| **개체명 인식 (NER)** | 가공되지 않은 텍스트에서 언급된 개체를 식별하고 분류하는 머신러닝 분류 시스템. |
| **관계 추출 (RE)** | 텍스트 내 개체 쌍 사이의 의미론적 관계를 식별하는 프로세스. |
| **전이 학습 (Transfer Learning)** | 일반적인 작업(예: 단어 예측)에서 학습한 언어 패턴과 지식을 다른 특정 작업(예: 관계 추출)에 재사용하는 능력. |
| **프롬프트 엔지니어링 (Prompt Engineering)** | 주어진 작업에 대해 가장 성능이 좋은 프롬프트를 식별하기 위해 자연어로 작업을 정밀하게 설계하고 개선하는 반복적인 과정. |
| **미세 조정 (Fine-tuning)** | 특정 도메인이나 작업에 대해 더 정확하고 안정적인 출력을 생성하도록 소량의 전용 데이터를 사용해 모델을 추가 학습시키는 과정. |
| **상호 참조 해결 (Coreference Resolution)** | 텍스트 내에서 '그', '그녀', 'R.'과 같은 대명사나 약어가 어떤 개체를 지칭하는지 식별하여 연결하는 작업. |
| **데이터 중심 패러다임 (Data-centric Paradigm)** | 모델 아키텍처보다 학습에 사용되는 데이터의 품질과 양을 개선하는 데 집중하는 머신러닝 접근 방식. |

---
**학습 팁:** 이 가이드는 록펠러 재단의 역사적 문서를 활용한 사례 연구를 바탕으로 작성되었습니다. 실제 학습 시에는 워런 위버(Warren Weaver)의 일기 분석 예시를 통해 프롬프트가 어떻게 진화하며 지식 추출의 정밀도를 높여가는지 복습하는 것이 좋습니다.
