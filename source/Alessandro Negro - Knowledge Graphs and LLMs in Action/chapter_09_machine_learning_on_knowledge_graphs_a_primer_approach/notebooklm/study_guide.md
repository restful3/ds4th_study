# 지식 그래프 기반 머신러닝 학습 가이드

이 가이드는 지식 그래프(Knowledge Graph, KG)에 머신러닝(ML)을 적용하는 핵심 개념, 작업 유형, 구현 방법론 및 주요 용어를 체계적으로 정리한 학습 자료입니다.

---

## 1. 핵심 개념 요약

### 지식 그래프와 머신러닝의 결합 목적
지식 그래프는 다양한 데이터 소스로부터 총체적인 지식을 획득하고 이를 탐색, 내비게이션 및 고급 분석이 가능한 형태로 표현합니다. 머신러닝을 지식 그래프에 적용하는 주된 이유는 다음과 같습니다.
*   **보편적 데이터 표현:** 그래프는 행렬, 텐서, 시계열 등 다양한 형태의 데이터를 변환하여 수용할 수 있는 범용적인 표현 방식을 제공합니다.
*   **문제 모델링의 단순화:** 노드 분류(이상 노드 탐지), 관계 예측(추천 및 상호작용 식별) 등 소수의 계산 작업으로 복잡한 현실 문제를 모델링할 수 있습니다.
*   **데이터 의존성 반영:** 전통적인 ML 알고리즘은 데이터가 독립적이고 동일하게 분포(i.i.d.)되어 있다고 가정하지만, 실제 데이터는 서로 연결되어 있습니다. 그래프는 이러한 고유한 관계 정보를 자연스럽게 저장하고 활용합니다.

### 지능형 자문 시스템(IAS)에서의 역할
지능형 자문 시스템은 사용자가 스스로 추출하기 어려운 통찰력을 제공합니다. 
*   **예시:** 약물 재창출을 위한 생물학적 개체 내비게이션, 맞춤형 치료 계획 수립.
*   **GNN과 LLM의 통합:** 그래프 신경망(GNN)은 복잡한 구조적 패턴을 감지하고, 대규모 언어 모델(LLM)은 이를 자연어로 이해하고 생성하여 전문적인 용어로 설명하는 역할을 수행합니다.

### 머신러닝 작업의 분류
그래프 기반 ML 작업은 크게 두 가지 범주로 나뉩니다.
1.  **노드 중심 작업 (Node-focused tasks):** 데이터 세트 전체가 하나의 그래프로 표현되며, 노드와 관계가 개별 데이터 포인트가 됩니다. (예: 노드 분류, 링크 예측)
2.  **그래프 중심 작업 (Graph-focused tasks):** 데이터 세트가 여러 개의 독립적인 그래프로 구성되며, 각 그래프 자체가 하나의 데이터 포인트가 됩니다. (예: 그래프 분류)

## 2. 단답형 연습 문제

**문 1. 전통적인 머신러닝에서 가정하지만, 그래프 데이터에서는 노드 간의 상호 연결성으로 인해 파괴되는 통계적 가정은 무엇인가요?**
**답:** 독립 동일 분포 (i.i.d. - Independent and Identically Distributed) 가정.

**문 2. 소셜 네트워크에서 비슷한 관심사나 특성을 가진 노드들이 서로 연결되는 경향을 무엇이라고 하나요?**
**답:** 동종선호 (Homophily).

**문 3. 존재하지만 기록되지 않았거나 미래에 발생할 가능성이 있는 노드 간의 연결을 식별하는 작업의 명칭은 무엇인가요?**
**답:** 링크 예측 (Link Prediction) 또는 관계 예측 (Relationship Prediction).

**문 4. 그래프 클러스터링에서 커뮤니티 내부의 실제 엣지 밀도와 기대 밀도의 차이를 최적화하여 그룹을 식별하는 지표는 무엇인가요?**
**답:** 모듈러리티 (Modularity).

**문 5. 노드의 구조적 역할을 캡처하기 위해 워드 임베딩 방식(Word2Vec)과 유사하게 랜덤 워크를 사용하는 자율 표현 학습 기법은 무엇인가요?**
**답:** Node2Vec.

**문 6. 관계를 벡터로 변환할 때 두 노드의 피처 벡터를 결합하기 위해 사용하는 수학적 연산자 중 하나를 제시하세요.**
**답:** 하다마드(Hadamard), 평균(Average), L1, L2, 연결(Catenation) 중 하나.

## 3. 심층 탐구를 위한 논술 주제

### 주제 1: 그래프 데이터에서 i.i.d. 가정의 파괴와 그에 따른 학습 전략의 변화
전통적인 ML은 각 데이터 포인트가 독립적이라고 간주하지만, 그래프의 노드는 관계를 통해 서로 영향을 주고받습니다(동종선호, 이종선호 등). 이러한 특성이 노드 분류 모델의 학습 방식(예: 준지도 학습의 활용)에 어떤 영향을 미치는지, 그리고 왜 노드의 특징(Attributes)뿐만 아니라 구조적 관계를 함께 모델링해야 하는지 논하시오.

### 주제 2: 특성 공학(Feature Engineering)과 자동화된 임베딩 기술의 균형
Zachary 카라테 클럽 사례에서 볼 수 있듯이 단순한 '학위(Degree)'나 Node2Vec 기반 임베딩보다 도메인 지식이 반영된 특정 그룹과의 연결 정도를 활용했을 때 성능이 비약적으로 향상되었습니다. 그래프 머신러닝에서 도메인 지식의 중요성과 GNN과 같은 자동화된 표현 학습 기술이 이를 어떻게 보완하거나 대체할 수 있는지 분석하시오.

### 주제 3: 지능형 자문 시스템(IAS)에서의 그래프 머신러닝 활용 시나리오
의료 데이터(단백질, 질환, 약물)나 금융 트랜잭션 네트워크를 예로 들어, 노드 분류, 링크 예측, 커뮤니티 탐지가 각각 어떤 비즈니스 문제를 해결할 수 있는지 설명하고, 최종 사용자에게 설명 가능한 통찰력을 제공하기 위해 LLM이 어떻게 통합될 수 있는지 서술하시오.

## 4. 주요 용어 사전

| 용어 | 정의 및 특징 |
| :--- | :--- |
| **지능형 자문 시스템 (IAS)** | 그래프 데이터를 입력으로 사용하여 사용자에게 전문적인 통찰력과 권장 사항을 제공하는 시스템. |
| **노드 분류 (Node Classification)** | 그래프 내 레이블이 없는 노드에 대해 알려진 노드들의 정보를 바탕으로 레이블을 예측하는 작업. |
| **링크 예측 (Link Prediction)** | 노드 쌍 사이의 관계 존재 확률을 예측하는 작업. 관계 유형까지 예측할 경우 '관계 예측'이라고도 함. |
| **커뮤니티 탐지 (Community Detection)** | 그래프의 위상 구조만을 사용하여 노드 간의 밀접하게 연결된 그룹을 식별하는 비지도 학습 작업. |
| **그래프 분류 (Graph Classification)** | 분자 구조와 같이 전체 그래프를 하나의 데이터 포인트로 간주하여 해당 그래프의 속성(예: 독성, 용해도)을 분류하는 작업. |
| **동종선호 (Homophily)** | 유사한 특성을 가진 노드들이 서로 연결될 확률이 높은 현상. |
| **이종선호 (Heterophily)** | 노드들이 자신과 다른 특성을 가진 노드와 우선적으로 연결되는 현상. |
| **구조적 동등성 (Structural Equivalence)** | 유사한 이웃 구조를 가진 노드들이 기능적으로 유사한 속성을 공유하는 특성. |
| **피처 임베딩 (Feature Embedding)** | 그래프의 구조적 정보와 노드 속성을 벡터 공간의 수치 데이터로 변환하여 전통적인 ML 알고리즘이 처리할 수 있게 만드는 과정. |
| **준지도 학습 (Semisupervised Learning)** | 학습 시 레이블이 있는 데이터와 레이블이 없는 데이터를 모두 활용하는 방식. 노드 분류에서 흔히 나타남. |
| **라벨 전파 알고리즘 (LPA)** | 네트워크 전체에 레이블을 전파하여 동일한 레이블을 가진 노드들을 커뮤니티로 묶는 빠른 커뮤니티 탐지 기법. |
