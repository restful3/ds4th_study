# Biomedical Quiz

## Question 1
생물학적 지식 그래프(KG)에서 '전사체(Transcriptome)'를 가장 정확하게 설명한 것은 무엇입니까?

- [ ] 한 생물체의 전체 유전적 보완물이며 주로 DNA로 구성됩니다.
- [ ] 세포 내에서 합성되는 모든 기능적 단백질의 집합입니다.
- [x] 단백질 합성을 지시하며 유전자가 RNA 분자로 복사되는 과정을 통해 생성된 집합입니다.
- [ ] 세포의 생화학적 활동을 시작하는 아미노산 체인의 집합체입니다.

**Hint:** DNA에서 단백질로 가는 중간 단계의 분자와 과정을 생각해보세요.

## Question 2
그래프 분석에서 약하게 연결된 컴포넌트(WCC) 알고리즘의 주요 목적은 무엇입니까?

- [x] 전체 그래프 내에서 서로 분리된 하위 그래프(서브그래프)를 찾는 것입니다.
- [ ] 모듈성 점수를 최대화하여 커뮤니티의 계층 구조를 밝히는 것입니다.
- [ ] 특정 노드 사이의 최단 경로를 계산하여 관계의 강도를 측정하는 것입니다.
- [ ] 노드의 차수(Degree)를 기반으로 중요도가 높은 중심 노드를 식별하는 것입니다.

**Hint:** 그래프가 하나로 뭉쳐 있는지 아니면 여러 개의 조각으로 나뉘어 있는지 확인하는 상황을 가정해보세요.

## Question 3
질병 경로(Disease Pathway)를 그래프 이론적 관점에서 정의할 때 가장 적절한 설명은 무엇입니까?

- [ ] 질병 노드와 유전자 노드 사이의 직접적인 이분 그래프 연결입니다.
- [x] 특정 질병과 관련된 단백질들의 집합과 그들 사이의 상호작용으로 정의되는 PPI 네트워크의 하위 그래프입니다.
- [ ] 유전자와 증상 사이의 통계적 상관관계를 나타내는 경로들의 집합입니다.
- [ ] 모든 단백질 노드가 질병 노드와 반드시 일대일로 매칭되는 구조입니다.

**Hint:** PPI(Protein-Protein Interaction) 네트워크 안에서 특정 목적을 가진 부분 집합을 떠올려보세요.

## Question 4
그래프 메트릭 중 전도도(Conductance)에 대한 설명으로 옳은 것은 무엇입니까?

- [ ] 값이 높을수록 해당 서브그래프가 전체 네트워크와 더 강력하게 분리된 독립적인 커뮤니티임을 의미합니다.
- [ ] 서브그래프 내부의 실제 엣지 수를 가능한 모든 엣지 수로 나눈 비율입니다.
- [x] 서브그래프 내부 노드와 외부 노드 사이의 연결성을 측정하며, 값이 낮을수록 내부 결속력이 강함을 나타냅니다.
- [ ] 서브그래프 내에서 가장 큰 연결 컴포넌트에 포함된 노드의 비율을 계산합니다.

**Hint:** 울타리 안의 사람들이 외부 사람들과 얼마나 대화하는지 측정하는 지표와 비슷합니다.

## Question 5
Hetionet 분석에서 사용되는 DWPC(Degree-Weighted Path Count) 메트릭이 단순 경로 수(PC)와 차별화되는 핵심 요소는 무엇입니까?

- [ ] 경로의 길이에만 가중치를 두어 짧은 경로에 더 높은 점수를 부여합니다.
- [x] 경로 상에 있는 노드들의 연결 차수를 이용하여 '매우 잘 알려진 노드'의 영향을 하향 조정합니다.
- [ ] 그래프의 전체 노드 수에 비례하여 경로의 가중치를 정규화합니다.
- [ ] 경로가 포함된 커뮤니티의 밀도가 높을수록 더 높은 점수를 부여하는 방식입니다.

**Hint:** 유명한 연예인을 거쳐 아는 사람보다 흔치 않은 지인을 통해 연결된 사람의 희소성을 생각해보세요.

## Question 6
DWPC 계산에서 사용되는 경로 차수 곱($PDP$) 공식 $PDP(path) = \prod_{d \in D_{path}} d^{-w}$에서 $w$의 역할은 무엇입니까?

- [ ] 경로의 최대 허용 길이를 결정하는 임계값입니다.
- [ ] 노드 간의 연결 강도를 선형적으로 증가시키는 승수입니다.
- [x] 감쇠 지수(Damping Exponent)로서, 차수가 높은 노드의 영향력을 얼마나 줄일지 조절합니다.
- [ ] 두 노드 사이의 최단 경로만을 선택하도록 강제하는 필터입니다.

**Hint:** 값이 커질수록 인기가 많은(차수가 높은) 노드의 점수가 더 급격히 깎이게 됩니다.

## Question 7

- [x] 분석 결과를 해석하고 복잡한 경로 데이터를 임상적 통찰력으로 변환하는 보조 도구입니다.
