# 그래프 피처 엔지니어링: 수동 및 반자동 접근 방식 학습 가이드

이 문서는 그래프 기반 머신러닝(ML)의 핵심 과정인 그래프 피처 엔지니어링을 심도 있게 다룹니다. 제공된 자료를 바탕으로 그래프 요소를 벡터로 변환하는 다양한 기법과 그 수학적 배경, 그리고 실제 사기 탐지 네트워크에의 적용 사례를 체계적으로 정리하였습니다.

---

## 1. 핵심 개념 개요

### 그래프 표현의 도전 과제
머신러닝 알고리즘(로지스틱 회귀, 랜덤 포레스트, 딥러닝 등)은 그래프 구조를 직접 처리할 수 없습니다. 따라서 그래프의 노드, 관계, 또는 전체 그래프를 알고리즘이 이해할 수 있는 수치적 형태인 **벡터(Vector)**로 변환하는 과정이 필수적입니다. 이를 **벡터화(Vectorization)** 또는 **피처화(Featurization)**라고 합니다.

### 자동화 수준에 따른 피처 엔지니어링 스펙트럼
피처 추출 방식은 해석 가능성과 생성 효율성 사이의 균형점에 따라 세 가지로 분류됩니다.

| 방식 | 특징 | 해석 가능성 | 생성 효율성 |
| :--- | :--- | :--- | :--- |
| **수동 피처(Manual)** | 도메인 지식과 그래프 속성을 바탕으로 직접 설계 | 매우 높음 | 낮음 (노동 집약적) |
| **반자동 피처(Semiautomated)** | 도메인 지식과 자동 추출 기법의 결합 | 중간 | 중간 |
| **완전 자동 피처(Fully Automated)** | 표현 학습(Representation Learning)을 통해 자동 학습 | 낮음 | 매우 높음 |

### 수동 피처 엔지니어링의 가치
1. **해석 가능성:** 인간이 검증하고 이해할 수 있는 결과를 제공합니다.
2. **설계 통찰력:** 자동화된 접근 방식을 설계하는 데 필요한 기반 지식을 제공합니다.
3. **LLM 호환성:** 대규모 언어 모델(LLM)이 잘 이해된 그래프 알고리즘과 속성을 바탕으로 자율적인 추론을 수행할 수 있게 합니다.

---

## 2. 노드 피처의 유형

노드 피처는 분석 범위에 따라 크게 로컬(Local)과 글로벌(Global)로 나뉩니다.

*   **로컬 피처 (Local Features):** 노드의 1-홉(one-hop) 이웃 또는 **에고넷(Egonet)**을 고려합니다.
    *   **Ego:** 에고넷의 중심 노드.
    *   **Alter:** 에고 주변의 이웃 노드들.
*   **글로벌 피처 (Global Features):** 전체 네트워크 또는 대규모 부분에서의 노드 역할을 측정합니다. (예: 근접 중심성, 매개 중심성, PageRank 등)

---

## 3. 주요 그래프 알고리즘 및 지표

### 3.1 차수 (Degree)
노드가 가진 이웃의 수입니다. 사기 탐지 도메인에서는 이를 세분화하여 활용합니다.
*   **사기 차수 (Fraud Degree):** 사기꾼으로 식별된 이웃 노드의 수.
*   **합법 차수 (Legit Degree):** 정상 사용자로 식별된 이웃 노드의 수.
*   **전체 차수 (Total Degree):** 모든 직접적인 이웃의 합계.

### 3.2 삼각형 (Triangles)
세 노드가 서로 모두 연결된 하위 그래프입니다. 노드 간의 강한 유대 관계를 나타냅니다.
*   **사기 삼각형 (Fraud Triangles):** 타겟 노드를 제외한 나머지 두 노드가 모두 사기꾼인 경우.
*   **반사기 삼각형 (Semifraudulent Triangles):** 나머지 두 노드 중 한 명만 사기꾼인 경우.

### 3.3 밀도 (Density)
네트워크 내 노드들이 얼마나 촘촘하게 연결되어 있는지를 측정합니다.
*   **공식:** $d = M / [N(N - 1) / 2]$
    *   $M$: 실제 에지(관계)의 수.
    *   $N$: 노드의 수.
    *   $N(N - 1) / 2$: $N$개의 노드로 구성된 완전 그래프에서 가능한 최대 에지 수.

### 3.4 지오데식 경로 (Geodesic Path)
두 노드 사이의 최단 거리를 의미합니다. 사기 노드까지의 최단 거리와 특정 홉(hop) 거리 내에 있는 사기 노드의 수는 위험도를 측정하는 중요한 지표가 됩니다.
*   **추출 도구:** 다익스트라(Dijkstra) 알고리즘이 주로 사용됩니다.

### 3.5 근접 중심성 (Closeness Centrality)
한 노드가 네트워크의 다른 모든 노드에 얼마나 "가까운지"를 측정합니다.
*   **계산 방식:** 특정 노드에서 다른 모든 노드까지의 최단 거리 평균의 역수.
*   **특징:** 값이 높을수록 네트워크의 중심에 위치하며 정보나 사기 행위가 더 빠르게 확산될 수 있음을 시사합니다.
*   **비연결 그래프 처리:** 경로가 존재하지 않는 경우(무한대 거리)를 대비해 도달 가능한 노드만을 고려하는 정규화 전략을 사용합니다.

### 3.6 매개 중심성 (Betweenness Centrality)
노드가 다른 노드 쌍들 사이의 최단 경로에 얼마나 자주 등장하는지를 측정하여, 노드의 "다리(bridge)" 역할을 정량화합니다. 정보의 흐름을 통제할 수 있는 영향력을 나타냅니다.

## 4. 실습 및 복습 문제

### 단답형 퀴즈
1. 그래프 요소를 머신러닝 알고리즘이 처리할 수 있는 수치적 벡터로 변환하는 과정을 무엇이라 합니까?
2. 노드 본인과 그 직접적인 이웃들로 구성된 부분 그래프를 무엇이라 부릅니까?
3. 사기 탐지 네트워크에서 타겟 노드와 연결된 이웃 중 사기꾼의 수만을 계산한 지표의 이름은 무엇입니까?
4. 그래프 내의 세 노드가 서로 모두 연결되어 있을 때 형성되는 구조는 무엇입니까?
5. 노드 간의 최단 경로를 찾는 데 널리 사용되는 대표적인 알고리즘은 무엇입니까?

### 심층 탐구를 위한 에세이 주제
1. **해석 가능성과 자동화의 상충 관계:** 수동 피처 엔지니어링이 자동화된 표현 학습(Representation Learning)에 비해 갖는 장단점을 비교하고, 어떤 상황에서 수동 방식이 더 유리한지 논하시오.
2. **네트워크 구조와 위험 확산:** 근접 중심성(Closeness Centrality)과 사기 탐지의 상관관계에 대해 설명하고, 중심성이 높은 사기 노드가 전체 네트워크에 미치는 영향에 대해 서술하시오.
3. **피처 엔지니어링의 도메인 특화:** 일반적인 밀도(Density) 지표와 달리, 차수(Degree)나 삼각형(Triangle) 지표를 '사기'와 '합법'으로 구분하여 분석하는 것이 모델의 성능에 어떤 도움을 줄 수 있는지 기술하시오.

## 5. 주요 용어 사전 (Glossary)

| 용어 | 정의 |
| :--- | :--- |
| **Vectorization** | 그래프 데이터를 수치 벡터 형태로 변환하는 과정. |
| **Egonet** | 특정 중심 노드(Ego)와 그 직접적인 이웃(Alters) 및 그들 사이의 관계로 구성된 네트워크. |
| **Dijkstra Algorithm** | 그래프에서 노드 간의 최단 경로를 찾기 위해 반복적으로 방문하지 않은 노드 중 최단 거리 노드를 선택하는 알고리즘. |
| **Centrality** | 네트워크 내에서 노드의 중요도나 영향력을 나타내는 지표들의 총칭. |
| **Representation Learning** | 수동 설계 없이 그래프 구조로부터 피처를 자동으로 학습하는 방식. |
| **Geodesic Path** | 두 노드 사이를 연결하는 가장 짧은 경로. |
| **Farness** | 한 노드에서 다른 모든 노드까지의 최단 거리 합계 또는 평균. |
