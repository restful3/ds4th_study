# 지식 그래프 기반 검색 증강 생성(Graph RAG) 학습 가이드

본 가이드는 지식 그래프(Knowledge Graph, KG)와 대규모 언어 모델(LLM)을 결합하여 정확하고 신뢰할 수 있는 정보 검색 시스템을 구축하는 방법론을 다룹니다. 특히 검색 증강 생성(RAG)의 진화와 그래프 기반 접근 방식의 강점을 상세히 분석합니다.

---

## 1. 핵심 개념 요약

### AI 에이전트 (AI Agents)
AI 에이전트는 환경과 상호작용하며 특정 복합 작업을 수행하도록 설계된 자율적 엔티티입니다. 미리 정해진 지침만 따르는 전통적인 소프트웨어와 달리, 자율성, 적응성, "지능"을 갖추어 실시간으로 결정을 내리고 경험을 통해 학습합니다. AI 에이전트의 핵심 구성 요소는 다음과 같습니다:
*   **두뇌:** 추론을 담당하는 대규모 언어 모델(LLM)
*   **프롬프트:** 에이전트의 단계별 행동을 안내하는 지침
*   **도구(Tools):** 외부 데이터 소스나 API와 상호작용할 수 있는 함수 집합

### 검색 증강 생성 (Retrieval-Augmented Generation, RAG)
RAG는 사전 훈련된 생성 모델의 한계를 극복하기 위해 외부 데이터 소스(구조화된 데이터베이스 또는 비구조화된 텍스트)에서 질문과 관련된 문맥을 검색하여 모델에 제공하는 기술입니다. 이는 모델의 답변 범위를 제공된 문맥으로 제한하는 '접지(Grounding)' 기술로 작용하여 신뢰성을 높입니다.

### 벡터 기반 RAG vs. 그래프 기반 RAG (Graph RAG)
*   **벡터 기반 RAG:** 문서를 임베딩(고정 길이 벡터)으로 변환하여 벡터 데이터베이스에 저장하고, 유사도 검색을 통해 관련 문항을 찾습니다.
*   **그래프 기반 RAG:** 지식 그래프를 중심 지식 저장소로 활용합니다. 원시 텍스트뿐만 아니라 메타데이터, 고신뢰도 구조화 데이터(표, 온톨로지 등)를 통합하여 복잡한 다단계 추론(Multi-hop reasoning)을 가능하게 합니다.

## 2. 주요 용어 사전 (Glossary)

| 용어 | 정의 |
| :--- | :--- |
| **환각 (Hallucination)** | LLM이 학습 데이터에 없는 내용에 대해 그럴듯해 보이지만 사실과 다른 정보를 생성하는 현상. |
| **지식 컷오프 (Knowledge Cutoff)** | 모델 학습이 완료된 시점 이후의 최신 정보를 모델이 알지 못하는 상태. |
| **임베딩 (Embedding)** | 텍스트의 의미를 포착하여 고정된 길이의 밀집 벡터(Dense Vector)로 표현한 것. |
| **코사인 유사도 (Cosine Similarity)** | 두 벡터 사이의 각도를 사용하여 유사성을 측정하는 지표로, 벡터 검색의 핵심 메커니즘. |
| **Cypher** | 그래프 데이터베이스(예: Neo4j)를 쿼리하기 위해 사용되는 선언형 그래프 질의 언어. |
| **텍스트 속성 그래프 (Text-attributed Graph)** | 노드와 관계가 텍스트 속성을 가지는 그래프 형태. |
| **텍스트 쌍 그래프 (Text-paired Graph)** | 노드와 관계를 그것이 추출된 원래의 소스 문서와 연결하여 추적할 수 있는 그래프. |
| **ReAct (Reason and Act)** | 추론과 행동 능력을 통합하여 복잡한 환경에서 문제를 해결하는 에이전트 프레임워크. |

## 3. 단답형 연습 문제 (Short-answer Quiz)

**질문 1: LLM이 전문적인 도메인 지식에 대해 답변할 때 "환각"이 발생하는 주된 이유는 무엇입니까?**
*   **정답:** LLM은 시퀀스에서 가장 확률이 높은 다음 토큰을 예측하도록 훈련되었기 때문에, 학습 데이터에 없는 주제에 대해서도 자신의 파라미터에 인코딩된 경험을 바탕으로 사실 여부와 상관없이 그럴듯한 문장을 생성하기 때문입니다.

**질문 2: 벡터 검색 기반 RAG의 주요 한계점 중 "문맥 단절(Context Fragmentation)"이란 무엇을 의미합니까?**
*   **정답:** 문서를 작은 조각(Chunk)으로 나누어 독립적으로 처리함으로써, 여러 문서나 조각 사이에 걸쳐 있는 복잡한 다단계 관계를 놓치게 되는 현상을 의미합니다.

**질문 3: 그래프 RAG가 벡터 검색에 비해 "소음(Noise)" 문제에 강한 이유는 무엇입니까?**
*   **정답:** 지식 그래프는 질문과 관련된 특정 개체와 관계만을 정밀하게 추출할 수 있어, 벡터 검색 시 발생할 수 있는 '느슨하게 관련되거나 무관한 문서'의 유입을 차단하고 관련 정보의 밀도를 높이기 때문입니다.

**질문 4: 텍스트 쌍 그래프(Text-paired graph) 설계가 AI 시스템에 제공하는 핵심 이점은 무엇입니까?**
*   **정답:** 추출된 엔티티와 관계를 원래의 소스 문서로 역추적할 수 있게 하여, 정보의 투명성을 높이고 필요시 상세한 문맥이 담긴 원본 텍스트를 정확하게 검색할 수 있게 합니다.

**질문 5: ReAct 에이전트가 문제를 해결하는 반복적인 피드백 루프의 세 단계를 쓰시오.**
*   **정답:** 생각(Thought), 행동(Action), 관찰(Observation)

## 4. 심층 탐구를 위한 에세이 주제 (Essay Prompts)

### 주제 1: 기업용 AI 솔루션에서 RAG의 필수성과 한계 극복 방안
단순한 챗봇을 넘어 기업 운영에 실질적인 ROI를 제공하는 AI 에이전트를 구축하기 위해 왜 RAG가 필수적인지 설명하십시오. 또한 초기 RAG 모델인 벡터 검색 방식이 가진 한계(신선도, 투명성, 데이터 프라이버시 등)를 그래프 RAG가 어떻게 보완할 수 있는지 논하시오.

### 주제 2: 지식 그래프와 LLM의 시너지 - 정보 검색의 정확성 향상
"Lauritsen이 사이클로트론 연구와 어떤 관련이 있는가?"라는 질문에 대해 단순 임베딩 기반 검색이 실패할 수 있는 이유를 분석하고, 지식 그래프를 활용했을 때 검색 결과의 질이 어떻게 향상되는지 원천 데이터 모델링(엔티티 추출, 관계 정의 등) 관점에서 설명하십시오.

### 주제 3: 인간 중심의 AI 시스템 설계와 지식 그래프의 역할
소스 문맥에 따르면 "시스템은 인간을 대체하는 대신 증강해야 한다"고 강조합니다. 지식 그래프가 제공하는 '인간이 읽을 수 있는 형식'의 지식 표현이 도메인 전문가의 검증과 시스템의 투명성에 어떻게 기여하는지, 그리고 이것이 사용자 신뢰에 미치는 영향에 대해 서술하십시오.

### 주제 4: 복합적 질문(Aggregate Questions) 해결에서의 그래프 RAG의 우수성
"하버드 대학과 존스 홉킨스 대학 간의 공통 연구 주제는 무엇인가?"와 같이 여러 문서에 흩어진 정보를 통합해야 하는 질문에서, 벡터 검색이 가진 한계와 지식 그래프가 점들을 연결하여(Connecting the dots) 정답을 도출하는 과정을 비교 분석하십시오.
