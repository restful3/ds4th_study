# study-deck-v1 디자인 규칙

이 템플릿은 커넥트브릭 세미나 발표자료의 정보 위계와 발표 UX를 바탕으로 `ds4th study`에 맞게 경량화한 1280×720 HTML 덱이다. 커넥트브릭의 로고, 고객명, 발표 내용과 개인 브랜딩은 포함하지 않는다.

## 핵심 원칙

- 배경은 따뜻한 회백색, 액센트는 진청 한 색을 기본으로 사용한다.
- 한 슬라이드에는 하나의 메시지만 두고 제목, 한 줄 설명, 본문, takeaway 순서로 읽히게 한다.
- 기본 글자 크기를 줄여 내용을 밀어 넣지 않는다. 내용이 넘치면 슬라이드를 나눈다.
- 표지, 섹션, 일반 설명, 카드·KPI, 흐름, 코드, 요약 레이아웃을 우선 사용한다.
- 외부 폰트, CDN, 프레임워크 없이 발표 폴더만으로 동작해야 한다.
- 템플릿 CSS와 JavaScript는 발표 폴더에 복사한다. 과거 발표에 일괄 덮어쓰지 않는다.

## 제공 컴포넌트

- `.slide--cover`: 표지
- `.slide--section`: 장 구분
- `.two-col`: 2열 설명
- `.card-grid`, `.card`: 개념 또는 비교 카드
- `.kpi-grid`, `.kpi`: 숫자 중심 요약
- `.flow`, `.flow__step`: 순서와 과정
- `.code-block`: 코드와 명령 예시
- `.takeaway`: 슬라이드 하단 핵심 문장
- `.source-note`: 출처와 주석

## 편집 규칙

1. `index.html`의 예시 슬라이드를 발표 흐름에 맞게 교체한다.
2. 각 `<section class="slide">`에 내용을 설명하는 `aria-label`을 둔다.
3. 이미지에는 구체적인 `alt`를 적고 `assets/` 아래에 저장한다.
4. 인용, 데이터와 외부 이미지는 슬라이드 안에 출처를 표시한다.
5. 기본 제공 키보드 이동, 목차, 진행률, 테마, 전체화면 코드는 제거하지 않는다.
