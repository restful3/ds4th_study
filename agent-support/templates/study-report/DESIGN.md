# study-report-v1 디자인 규칙

이 템플릿은 커넥트브릭 세미나의 `report + slides` 듀얼 산출물 구조와 장문 리포트의 정보 위계를 `ds4th study`에 맞게 경량화한 HTML 리포트다. 커넥트브릭의 로고, 고객명, 발표 내용과 개인 브랜딩은 포함하지 않는다.

## 역할

- 리포트는 발표 중 생략한 정의, 배경, 근거, 사례와 판단 기준을 보존하는 사후 학습 자료다.
- 발표자료와 같은 결론을 공유하되 슬라이드 문장을 늘이는 방식으로 작성하지 않는다.
- 한 회차에는 기본적으로 `report.html`과 발표자료 `index.html`이 함께 있어야 한다.

## 정보 구조

1. 표지와 회차 메타데이터
2. Executive summary와 핵심 메시지
3. 장의 논리를 따르는 상세 본문
4. 적용 사례와 판단 질문
5. 핵심 용어와 참고 자료

## 디자인 원칙

- 따뜻한 회백색 배경, 흰색 본문 면과 진청 단색 액센트를 사용한다.
- 본문 최대 폭은 약 760px로 제한하고 한글 본문 행간은 1.8 안팎으로 둔다.
- 데스크톱에는 고정 목차를, 모바일에는 접을 수 있는 목차를 제공한다.
- 외부 폰트, CDN과 프레임워크 없이 회차 폴더만으로 읽을 수 있어야 한다.
- 인쇄 시 제어 버튼과 목차 패널을 숨기고 A4 페이지에 자연스럽게 나뉘어야 한다.

## 제공 컴포넌트

- `.report-cover`: 표지
- `.executive-summary`: 핵심 요약
- `.report-section`: 본문 섹션
- `.callout`: 핵심 메시지·주의·판단 포인트
- `.concept-grid`, `.concept-card`: 개념 비교
- `.process`: 단계와 반복 구조
- `.comparison-table`: 비교표
- `.decision-list`: 도입 판단 질문
- `.glossary`: 핵심 용어

## 편집 규칙

1. `index.html`의 예시 본문을 회차 내용으로 교체한다.
2. 모든 목차 링크와 본문 `id`를 일치시킨다.
3. 책 원문을 길게 복제하지 않고 발표자의 설명과 구조로 재구성한다.
4. 이미지에는 구체적인 `alt`를 적고 회차 `assets/` 아래에 저장한다.
5. 인용, 수치, 외부 이미지에는 출처를 표시한다.
6. 기본 제공 목차, 읽기 진행률, 테마와 인쇄 기능을 제거하지 않는다.
