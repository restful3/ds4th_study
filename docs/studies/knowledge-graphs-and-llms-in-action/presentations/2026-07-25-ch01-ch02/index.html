ds4th studyREPORT §3.2–3.3

서로가 상대의 약점을 정확히 세 곳씩 메운다

한쪽이 다른 쪽을 대체하지 않고 구축과 이용의 양방향 수명주기에서 책임을 주고받습니다.

LLM → KG

접근 장벽을 낮춘다

  • 구축 — 프롬프트만으로 개체·관계 범용 추출
  • 질의 — 자연어를 text-to-cypher로 정밀 질의화
  • 요약 — 표·차트가 아닌 글로 결과 전달

KG → LLM

신뢰의 토대가 된다

  • 환각 — 검증된 지식으로 사실의 토대 제공
  • 오래된 정보 — 계속 갱신·GraphRAG로 최신 공급
  • 설명 가능성 — 추적·검증 가능한 근거 경로

핵심 — 두 기술의 강점이 상대의 약점과 맞물려 서로를 강화하는 “환상의 조합”이 됩니다.
